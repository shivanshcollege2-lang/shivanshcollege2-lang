### ⚡ ChargeFlow — EV Charging Station Management & Booking Network

A three-tier EV charging application simplifying station discovery, charger filtering, conflict-free time-slot reservations, and live charging-session lifecycle tracking.

* **Tech Stack:** `React.js` · `Node.js` · `Express.js` · `MySQL` · `JWT`
