## 🚀 Featured Projects

### 🔍 SignalGuard — Application Reliability & Incident Detection Platform

**Status:** In Progress

A monitoring platform designed to analyze API latency, error rates, traffic patterns, and application logs to identify abnormal service behavior and support incident investigation.

**Key areas:** Telemetry monitoring, anomaly detection, risk scoring, and service-health dashboards.

**Tech Stack:** React.js · Node.js · Express.js · Python · FastAPI · PostgreSQL

---

### 🧾 InvoiceEye — Smart Invoice Verification System

An invoice-processing project designed to extract structured information from invoices and validate it against vendor records and purchase orders.

**Key areas:** OCR-based extraction, field normalization, quantity and pricing checks, duplicate detection, discrepancy explanations, and verification history.

**Tech Stack:** React.js · Node.js · Express.js · MySQL · Python · OCR · JWT

---

### ⚡ ChargeGrid — EV Charging Platform

A full-stack EV charging application supporting station discovery, charger selection, time-slot booking, and charging-session workflows.

**Key areas:** REST APIs, authentication, role-based authorization, booking validation, and conflict handling.

**Tech Stack:** React.js · Node.js · Express.js · MySQL · JWT

---

### 🔐 AccessFlow — Campus Access Management Platform

A role-based campus access-management application supporting pass requests, administrative approvals, and security verification workflows.

**Key areas:** Google OAuth, JWT authentication, QR-based pass verification, server-side validation, and role-based access control.

**Tech Stack:** React.js · Node.js · Express.js · MySQL · Google OAuth · JWT

---

### 📊 DataPilot — CSV Analytics Application

A data analytics application focused on importing, processing, exploring, and visualizing structured CSV data.

**Key areas:** Data ingestion, preprocessing, exploratory data analysis, interactive visualizations, and analytical reporting.

**Tech Stack:** Python · Data Analysis · Data Preprocessing · Data Visualization
